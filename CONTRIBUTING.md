# Contributing

Please open an issue before adding a data source or changing an acceptance
threshold. Source additions must document score-level licensing evidence; a
repository's software license is not sufficient by itself.

Run the complete test suite before submitting a change:

```bash
python -m unittest discover -s tests -v
```

Do not commit downloaded scores, tokens, generated output, or release archives.
Code contributions are accepted under the MIT License. Metadata describing
third-party scores remains factual provenance and does not change score rights.
